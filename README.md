# SQL Sales Analysis

## Project Overview
This project focuses on analyzing sales data using SQL to identify business trends and generate meaningful insights.

## Objectives
- Analyze total sales and revenue.
- Identify top-performing product categories.
- Understand customer purchasing patterns.
- Compare sales performance across cities.
- Practice SQL queries to solve business problems.

## Tools Used
- MySQL
- SQL

## SQL Skills Demonstrated
- SELECT and WHERE
- GROUP BY and HAVING
- Aggregate functions
- JOINs and subqueries
- Common Table Expressions (CTEs)
- Window functions
