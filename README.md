# 🎮 Video Game Sales Analysis using SQL

## 📌 Project Overview

This project analyzes video game sales data using MySQL to explore genre performance, global sales trends, and regional market differences.

The analysis answers 10 business questions using SQL queries to turn raw sales data into meaningful business insights.

## 🎯 Business Objectives

- Identify the highest and lowest performing video game genres.
- Calculate total global sales and genre-wise sales contribution.
- Rank genres based on total sales and average sales per game.
- Analyze year-over-year sales changes by genre.
- Identify the top 3 genres in each decade.
- Calculate running sales totals for the highest-selling genre.
- Compare sales performance across different regions.

## 🛠️ Tools & Technologies

- MySQL
- SQL

## 📊 Key SQL Concepts Used

- Aggregate functions: `SUM()`, `AVG()`, `COUNT()`
- Joins
- `GROUP BY` and `HAVING`
- Subqueries and Common Table Expressions (CTEs)
- Window functions: `RANK()` and `LAG()`
- Running totals using window functions
- Conditional analysis using `GREATEST()` and `LEAST()`

## 📁 Project Structure

- `video_game_sales_analysis.sql` — SQL queries for all 10 business tasks.

## 🔍 Analysis Performed

1. Total sales by genre.
2. Genres with above-average total sales.
3. Percentage contribution of each genre to global sales.
4. Ranking genres by total sales.
5. Average sales per game by genre.
6. Year-over-year genre sales changes.
7. Top 3 genres by decade.
8. Running total of yearly sales for the top genre.
9. Least popular genres by sales and number of games.
10. Genre with the largest variation across regions.
